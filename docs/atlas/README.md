# Product Factory Atlas

**Status:** Active

The one-page map of what Product Factory is, what is implemented, and where its
rules and evidence live. It follows the Connect Atlas convention: settled facts
link to their owning documents; current limits are stated as current limits.

- [Atlas in English](ATLAS.md)
- [اطلس فارسی](ATLAS.fa.md)
- [Visual Atlas](ATLAS.html) — self-contained browser page with English/Persian
  and light/dark controls.
- [Usage guide](../guide/09-day-to-day-usage.md) · [راهنمای استفاده](../guide/09-day-to-day-usage.fa.md)

Update both language pages and the visual Atlas in the same change when a
factory decision, component boundary, installation path, or verified state
changes. Role and procedure details remain in the kit and are linked from the
Atlas. The visual page summarizes the Markdown pages; they own the full facts.
