The rules of the factory. [CONSTITUTION.md](CONSTITUTION.md) is the single source
of truth for authority, scope, evidence and documentation rules. Every other
file applies it, and a file that disagrees with it is a defect.

`kit/.claude/skills/factory/CONSTITUTION.md`, a link to this file, and the
installer copies it into each product at `.claude/skills/factory/CONSTITUTION.md`.
Edit it only here.

Its contract (sections, enforcement, change checklist) is
[COMP-013](../components/COMP-013-constitution.md).
